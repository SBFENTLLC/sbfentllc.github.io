# SBFENT: Stamped Out — first combat prototype

Private test: https://sbfent-stamped-out-test.purpleflute8.chatgpt.site

This review build contains Flex A Lot versus The Bootlegger on one rooftop. It includes touch and keyboard controls, AI difficulty, passive training, punch, kick, block, jump, crouch, charged special, best-of-three rounds, pause, rematch, and synthesized impact sounds. The 16-fighter roster, alternate outfits, story chapters, unlockable bosses, additional stages, throws, and soundtrack remain planned work after combat review.

Serve this directory through an HTTP static server to play. No dependencies or external asset services are required. Run `node --test stamped-out/engine.test.mjs` from the repository root. Eight simulation tests passed; no browser/device QA was available in this environment. Generated artwork is included as WebP assets. Source images were generated with the built-in image tool from the supplied character references.
